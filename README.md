# MS5130
Exploring Socioeconomic and Psychological Factors Using Data Analysis
📌 Project Overview
This project explores the impact of socioeconomic factors on psychological well-being, specifically analyzing relationships between life expectancy, happiness scores, GDP per capita, and suicide rates. The study leverages statistical analysis and data visualization to uncover key insights.

🔍 Key Objectives
Investigate how GDP per capita, life expectancy, and happiness influence suicide rates.
Perform statistical analysis using R and SPSS.
Apply hypothesis testing and regression modeling to assess variable relationships.
Visualize key trends using ggplot2 and Plotly.
🛠 Technologies & Tools
Programming Languages: R
Libraries: ggplot2, plotly, dplyr
Statistical Methods: Linear Regression, T-Tests, Correlation Analysis
Data Sources: Merged datasets on depression, life expectancy, and suicide rates
📊 Analysis & Findings
Conducted data merging & cleaning for structured analysis.
Built regression models to predict suicide rates based on socioeconomic indicators.
Developed interactive visualizations to highlight trends.
